# Documentation index

Start with the [README](../README.md). Then read only the guides that match your task.

## Start here

| Guide | Read it when |
| --- | --- |
| [beginner-guide.md](beginner-guide.md) | You are new to Python, virtual environments, Postgres, FastAPI, or the command line. Agents use it to explain concepts. |
| [google-oauth-walkthrough.md](google-oauth-walkthrough.md) | You create the Google client ID and secret, and set the redirect URIs. |

| [choosing-options.md](choosing-options.md) | You consider Logto instead of Google, or Railway instead of Render. |
